1. 概要とアクセス方法

ブラウザで以下のURLを開くだけで使えます。アプリのインストールは不要です。

URL： https://murakijun.github.io/farm-manager/

スマートフォンのホーム画面に追加しておくと、アプリのように使えます。

  • iPhone（Safari）：「共有」ボタン →「ホーム画面に追加」
  • Android（Chrome）：右上メニュー →「ホーム画面に追加」

このシステムでできること

機能内容
ハウス管理複数のハウスを登録し、ハウスごとに木を管理する
木の状態記録一本ずつ「正常・注意・病気・枯死」の状態を記録する
写真とメモ木の様子を写真で残し、気になることをメモする
作業チェックリスト農薬散布・剪定などの作業をハウス単位で管理する
作業時間の打刻ハウスに入るとき・出るときにボタンを押すだけで時間を記録する
集計月別・ハウス別・作業種類別の作業時間を自動で集計する
エクセル出力記録したデータをエクセルファイルで保存・印刷できる
注意： データはお使いの端末のブラウザ内にのみ保存されます。ブラウザのデータを消去するとすべて消えるため、月に1回はエクセル出力でバックアップを取ることをおすすめします。複数の端末でのデータ共有には対応していません。

2. ホーム画面（ハウス一覧）

URLを開くと最初に表示されるのがホーム画面です。登録されたハウスがカード形式で並んでいます。

┌───────────────────────────────────────┐
│ 🌳 農場 木管理   [時間管理]  [ホーム]   │ ← 上部ナビゲーション
└───────────────────────────────────────┘

┌────────────────────────────────┐
│ 1号棟                          │
│ 木 24本   正常:20  注意:3  病気:1│ ← ハウスカード
│                   [詳細を見る] │
└────────────────────────────────┘

         ＋ 新しいハウスを追加

ハウスの追加

1画面下部の「＋ 新しいハウスを追加」ボタンを押す
2ハウス名・行数・列数を入力する（例：1号棟、6行 × 4列）
3「保存」を押す

行数と列数はハウスに実際に植えてある木の配置に合わせて設定します。後から変更も可能です。

ハウスの削除

ハウス詳細画面の右上「編集」→「削除」から削除できます。

削除すると、そのハウスの木・写真・作業記録がすべて消えます。間違えないよう注意してください。

3. ハウス詳細画面

ホームでハウスのカードをタップすると、ハウス詳細画面が開きます。

木のグリッド表示

ハウスに植えてある木が格子状（グリッド）に表示されます。各マスが木1本を表しています。マスの色が木の状態を示します。

色状態意味
緑 正常 健康な状態
オレンジ 注意 様子を見たほうがよい
赤 病気 治療・対応が必要
グレー 枯死 枯れてしまった木 
     1列  2列  3列  4列
1行 [緑 ] [緑 ] [橙 ] [緑 ]
2行 [緑 ] [赤 ] [緑 ] [緑 ]   ← マスをタップ → 木の詳細へ
3行 [緑 ] [緑 ] [緑 ] [灰 ]

作業時間の打刻

ハウス詳細画面の上部に「作業開始」ボタンがあります。

操作手順
作業を始めるとき 「作業開始」ボタンを押す → 作業の種類を入力（例：剪定）→ 経過時間がリアルタイムで表示される
作業が終わったとき 「作業終了」ボタンを押す → 作業時間（〇時間〇分）が表示される
作業の種類は自由に入力できます。過去に入力した作業名は候補として表示されるので、選んで入力の手間を省けます。

ハウスの編集

右上の「編集」ボタンから、ハウス名・行数・列数を変更できます。

4. 木の管理

グリッドのマスをタップすると、その木の詳細画面が開きます。

状態の変更

画面上部に4つのボタンが並んでいます。現在の状態のボタンが選択されています。ボタンを押すと即座に保存され、グリッドの色もすぐに変わります。

正常 注意 病気 枯死

メモの記録

「メモ」欄に気になることを自由に入力できます。入力後「保存」ボタンを押してください。日付は自動で記録されます。

写真の撮影・追加

1「写真を追加」ボタンを押す
2スマートフォンのカメラが起動する（またはカメラロールから選択できる）
3撮影・選択すると自動で保存される

写真は画面下部にサムネイル一覧で表示されます。タップすると大きく見られます。写真は容量を節約するため自動的に縮小されます。

写真を削除するには、サムネイルの右上の「×」ボタンを押します。

5. 作業チェックリスト

ハウス詳細画面の下部に「作業記録」のセクションがあります。農薬散布・剪定などの作業の進捗をハウス単位で管理できます。

作業の追加

1「新しい作業を追加」ボタンを押す
2作業名を入力する（例：5月第1回 農薬散布）
3作業日を入力する
4「保存」を押す

チェックの付け方

作業を開くと、そのハウスの全木がグリッドで表示されます。作業済みの木をタップするとチェックが入り（緑色に変わる）、もう一度タップするとチェックが外れます。

作業：5月第1回 農薬散布

     1列   2列   3列   4列
1行 [済✓] [済✓] [済✓] [済✓]
2行 [済✓] [済✓] [    ] [    ]  ← ここまで作業済み
3行 [    ] [    ] [    ] [    ]

作業の削除

作業詳細画面の下部にある「この作業を削除」ボタンから削除できます。

6. 時間管理（打刻）

作業時間の記録は2か所で行います。ハウスの詳細画面で打刻し、時間管理ページで一覧を確認します。

作業時間の打刻（ハウス詳細画面）

基本の流れ： ハウスに入ったら「作業開始」→ 終わったら「作業終了」を押すだけです。
▶ 開始するとき
1作業するハウスの詳細画面を開く
2「作業開始」ボタンを押す
3作業の種類を入力する（例：剪定、農薬散布）
4経過時間がリアルタイムで画面に表示される
■ 終了するとき
1同じハウスの詳細画面を開く
2「作業終了」ボタンを押す
3作業時間（〇時間〇分）がポップアップで表示される

1日に複数のハウスで作業した場合は、それぞれのハウスで開始・終了を行います。

時間管理ページ（一覧）

上部ナビゲーションの「時間管理」ボタンを押すと一覧ページが開きます。記録は日付ごとにまとめて表示されます。

┌───────────────────────────────────────────┐
│ 10月1日（水）                  合計 3時間25分 │
│  1号棟  剪定      9:00 〜 11:30    2時間30分 │
│  2号棟  農薬散布  13:00 〜 13:55      55分   │
└───────────────────────────────────────────┘
┌───────────────────────────────────────────┐
│ 9月30日（火）                  合計 2時間10分 │
│  3号棟  水やり    8:30 〜 10:40    2時間10分 │
└───────────────────────────────────────────┘

過去の月は画面上部の「◀ 前月」ボタンで移動できます。

記録の削除

各セッションの右端にある「🗑」ボタンを押すと、その打刻記録を削除できます。

7. 集計

時間管理ページ右上の「集計」ボタンを押すと集計ページが開きます。打刻したすべての記録が自動で集計されます。

月別 合計時間

月ごとの合計作業時間と稼働日数が一覧で表示されます。月名をタップするとその月の打刻一覧に移動します。

年月稼働日数合計時間
2026年10月3日8時間45分
2026年9月18日62時間20分

作業の種類別 合計時間

全期間の記録を作業種類（農薬散布・剪定など）ごとに集計します。どの作業に一番時間をかけているかを確認できます。

ハウス別 作業時間

全期間の記録をハウスごとに集計します。ハウス名をタップするとそのハウスの詳細画面に移動します。

8. エクスポート（エクセル出力）

記録したデータをエクセルファイル（.xlsx）として書き出せます。パソコンで開いて印刷したり、バックアップとして保存したりできます。

出力できるファイル

ボタンの場所出力ファイル名内容
時間管理ページ（一覧） ハウス作業時間_YYYY-MM.xlsx 表示中の月のハウス別打刻一覧（日付・曜日・ハウス・作業種類・開始〜終了・時間）
集計ページ ハウス作業時間_YYYY-MM.xlsx 今月のハウス別打刻一覧（日計サマリー付き）

出力手順

1時間管理ページまたは集計ページを開く
2「エクセル」ボタンを押す
3端末のダウンロードフォルダに .xlsx ファイルが保存される

スマートフォンの場合は、ダウンロードしたファイルをメールやAirDropでパソコンに転送してください。

バックアップについて： データはブラウザ内に保存されているため、ブラウザのキャッシュ削除やアプリの削除でデータが消えます。月に1回はエクセル出力でバックアップを取ることを強くおすすめします。
